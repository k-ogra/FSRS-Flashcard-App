# FSRS Flashcard App

A modern flashcard application powered by the Free Spaced Repetition Scheduler 6 (FSRS-6) algorithm, designed to help you study smarter and remember more.

## Features

### FSRS-6 Algorithm

Uses spaced repetition to predict when you'll forget a card and schedules reviews accordingly.

### Media Integrated Cards

Create media integrated cards with images or audio.

### Shareable Decks

Browse and share decks created by other users. Or create your own decks and share them with the public.
